# FIFA 20 Player Data Analysis

## Project Overview
This project performs exploratory data analysis (EDA) on the FIFA 20 player dataset to understand player statistics, ratings, positions, and market values.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data cleaning and preprocessing
- Player rating distribution
- Player value and wage analysis
- Position-wise player analysis
- Data visualization

## Goal
The goal of this project is to explore FIFA 20 player data and gain insights using data analysis and visualization techniques.
